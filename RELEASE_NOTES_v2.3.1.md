# Release Notes — Ren'Py Translator v2.3.1

Ren'Py Translator v2.3.1 is a patch release focused on packaging reliability and language support.

## Fixed

- Added `ctk_components.py` to the Windows, macOS, Linux and generic release packages. This fixes the `ModuleNotFoundError` that prevented packaged builds from starting after the v2.3.0 GUI restyle.

## Added

- Added Turkish (`tr`) as a supported source and target language across the GUI and translation backends.
